# GREEN — Сладкий сезон больших подарков

Лендинг рекламной игры по исходному макету Figma.

Локальный проект: `C:\Work\GlobalProg\2026-Рома-ПромИгры\green`.
Репозиторий: https://github.com/RomanKadevich/green

## Запуск

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

Сборка: `npm run build`. Проверка lossless WebP: `npm run check:assets`.
Выходные файлы сайта находятся в `dist/client`.

## Макет и проверка

Исходный файл: https://www.figma.com/design/xyQjX9MoJGpxK1UVIACjQ3/

| Версия | Figma node | Размер эталона |
| --- | --- | --- |
| Desktop | `3745:11534` | 1920 × 5419 |
| Tablet | `3797:16623` | 1024 × 4589 |
| Mobile | `3831:4012` | 430 × 4639 |

Эталоны: `design/references/`. Отчёт визуальной проверки: `design-qa.md`.
Для статического сравнения используйте `/?motion=off`; обычная страница воспроизводит снегопад в двух блоках.

Вёрстка — статический HTML и CSS, интерактивы — обычный JavaScript. React и другие UI-фреймворки не используются. Vite нужен только для разработки и сборки; текст страницы уже присутствует в `index.html`, а FAQ работает через нативные `details`/`summary`. Фотографии, рекламные композиции и декоративные надписи извлечены из оригинальных слоёв Figma. Все 28 растровых изображений сохранены в WebP lossless; логотип и небольшие оригинальные пиктограммы — SVG. Шрифты загружаются локально из npm-пакетов Fontsource.

Дата начала — **20.11.2026** на всех экранах по последнему уточнению пользователя. Остальные даты и текст сохранены отдельно для каждого брейкпоинта, включая исходные расхождения.

Снегопад воспроизводит измеренные в Figma линейные переходы: вступление 5003 мс, затем цикл 12107 мс. Геометрия и прозрачность каждого ключевого кадра находятся в `src/motion-data.json`, параметры переходов и измерения блоков — в `design/measurements/`. Та же последовательность адаптирована для блока призов. Настройка системы «уменьшение движения» отключает анимацию. Для проверки отдельного момента используйте `/?motion-time=5003` (время исходной последовательности в миллисекундах).

## Границы текущей реализации

Работают якорная навигация, мобильное меню, обе карусели, раскрытие вопросов и модальные окна. Вход в личный кабинет, официальные PDF/юридические документы, результаты розыгрышей и прямые ссылки на приложения требуют данных организатора. Авторизация и сервер участия в этот лендинг не включены. Ответы FAQ, кроме первого, являются предварительным текстом для проверки интерфейса.

## Повторное извлечение графики

Большие исходные SVG экспорты сохранены локально в `design/exports/`, вне Git. Скомпилированные WebP/SVG в `public/assets/` достаточны для запуска и сборки из чистого клона.

Служебные скрипты `inspect-design.py`, `extract-artwork.py` и `render-artwork.mjs` сохраняют исходные размеры и маски Figma. `extract-motion.py` извлекает геометрию раскадровки, `generate-html.py` помогает повторно сформировать HTML и таблицу размеров из сохранённых измерений. Эти скрипты предназначены для подготовки исходников, не выполняются при сборке и не зависят от доступности Figma во время работы сайта.
