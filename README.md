# GREEN — Сладкий сезон больших подарков

Статический лендинг по [макету Figma](https://www.figma.com/design/xyQjX9MoJGpxK1UVIACjQ3/).

## Файлы сайта

- `index.html` — разметка и текст.
- `css/style.css` — стили и адаптивная вёрстка.
- `js/main.js` — меню, карусели, FAQ, диалоги и снегопад.
- `assets/` — оригинальные изображения WebP lossless и SVG из Figma.
- `assets/fonts/` — локальные Roboto, Manrope и Montserrat, лицензии в `LICENSES.txt`.

Изображения разделены по целым объектам: фон, машина, набор товаров, декоративный заголовок, фото призов и логотипы. Машина повторно используется в блоке главного приза. Сложные декоративные надписи «Выиграй GEELY» — небольшие самостоятельные SVG из макета. Рамки карточек, панель правил, круги с номерами, обычные заголовки и подписи построены в HTML/CSS. Для крупных изображений браузер выбирает вариант под размер экрана.

Обычные блоки расположены через Flex/Grid и отступы. В HTML нет координат и встроенных стилей; отдельные версии целых блоков для разных экранов не дублируются. Абсолютные позиции оставлены для наложений: баннера, счётчиков призов и декора. В CSS блоки подписаны комментариями: шапка, баннер, правила, карточки, FAQ, подвал. Переменная `--u` в начале файла отвечает только за масштабирование размеров трёх исходных макетов.

Сборка и установка зависимостей не требуются. Для публикации достаточно загрузить `index.html`, `css/`, `js/` и `assets/` на любой статический хостинг. Относительные пути позволяют разместить сайт также в подкаталоге.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт через GitHub Actions без сборки и установки зависимостей.

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Во вкладке **Actions** откройте **Deploy GREEN to GitHub Pages** и нажмите **Run workflow → Run workflow**, выбрав ветку `main`.

После успешного запуска адрес сайта: https://romankadevich.github.io/green/. Дальнейшие push в `main` автоматически обновляют сайт. Публикуются только `index.html`, `css/`, `js/` и `assets/`.

## Локальный просмотр

В корне проекта:

```sh
python -m http.server 4174 --bind 127.0.0.1
```

Откройте http://localhost:4174/. Системная настройка уменьшения движения отключает снегопад. Для визуальной сверки: `/?motion=off`; для конкретного момента анимации: `/?motion-time=5003`.

## Особенности макета

Эталоны: desktop 1920 × 5419, tablet 1024 × 4589, mobile 430 × 4639. Начало акции — **20.11.2026** на всех экранах. Остальные различия дат и текста сохранены по исходным макетам.

Снегопад сверён с предоставленной записью Figma от 31.10.2026. Четыре снежинки входят сверху в разное время, продолжают падать во время плавного исчезновения и повторяются независимо друг от друга, без общей паузы. Дата и плашка «Выиграй» появляются в начале. Такой же принцип применён в блоке призов. Надписи Circe Bold в мобильном меню — оригинальные SVG-контуры внутри доступных HTML-ссылок и кнопки.

Логотипы GREEN в шапке и подвале, а также обе ссылки «Личный кабинет» временно ведут на https://www.green-market.by/. Официальные документы, результаты розыгрышей и прямые ссылки на приложения требуют данных организатора. Ответы FAQ, кроме первого, — предварительный текст. Авторизация и сервер участия не входят в лендинг.

FAQ плавно раскрывается и закрывается за 220 мс. Карусели циклично сдвигаются на одну карточку за 320 мс, работают стрелками и горизонтальным свайпом. При уменьшении движения переход мгновенный. Мобильное меню сохраняет шесть снежинок и подстраивает вертикальные отступы под высоту экрана; рамки мокапа телефона нет. Ошибочная строка с тремя юридическими ссылками из подвала удалена.
